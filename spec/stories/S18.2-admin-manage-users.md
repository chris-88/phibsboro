# S18.2 — Admin: promote/demote admins and fully delete a person

| | |
|---|---|
| **Epic** | 18 — Manager conveniences (post-v1.3.0) |
| **Status** | Done |
| **Depends on** | S14.2 (admin user manager) |
| **Size** | S |

## Goal
Two capabilities the admin user manager lacked (Chris, 2026-09-16): an admin can **make another
person an admin** (or remove it), and can **fully delete a person** — account and all their data.

## Context
`is_admin()` reads `profiles.is_admin` (D2), so "make admin" is that flag. `profiles` is not
client-writable for it, and `auth.users` is off-limits to clients, so both go through admin-only
security-definer RPCs, the pattern of `admin_set_membership` (W6). Deleting the auth account cascades:
`profiles.id references auth.users on delete cascade`, and every user-keyed row references
`profiles(id) on delete cascade` — memberships, responses, attendance, squad picks, match stats,
feedback. `created_by` columns are `set null`, so an event a deleted manager created survives.

## Scope
**In**
- `admin_set_admin(user_id, is_admin)` — admin-only; refuses stripping one's **own** admin.
- `admin_delete_user(user_id)` — admin-only; refuses deleting **oneself**; removes the auth account.
- Admin Users screen: an **Admin** badge; a **Make admin / Remove admin** button; a **Delete user…**
  action behind a type-the-name confirm (the same guard as the event hard-delete, S4.2). Both hidden
  on the admin's own row.

**Out**
- Bulk actions. Un-deleting / soft-delete (there is no undo — the confirm is the guard). Transferring
  a deleted person's history to someone else.

## Acceptance criteria
- [x] **AC1** — An admin promotes/demotes another admin; the badge and buttons follow.
- [x] **AC2** — An admin permanently deletes a person; their profile and every keyed row cascade away.
- [x] **AC3** — Both refuse a non-admin in the DB (`not_authorised`), and refuse the admin acting on themselves.
- [x] **AC4** — Delete is behind a type-the-name confirm; the actions never show on the viewer's own row.
- [x] **AC5** — `anon` holds no execute on either RPC.
