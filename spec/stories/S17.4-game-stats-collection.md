## Goal
A manager runs a match from one screen: tap a goal/assist/card against a player as it happens, set minutes,
pick man of the match, and enter the final score — and can correct it all after the whistle.

## Context
[X5](../00-decisions-v1.3.0.md). The pool is the **selected squad** (`event_squad`, S9.2). Writes are
optimistic upserts (D48), mirroring `attendance` (S4.5), so the sideline experience is instant and offline-
tolerant. Same screen edits an old match.

## Scope
**In**
- A collection screen for a match (from the Squad tab, S17.2): the selected squad listed with, per player,
  **+/-** for goals / assists / yellows, a **red** toggle, and a **minutes** input.
- Top of screen: a **MOTM** picker (one of the squad, → `events.motm_user_id`) and the **score** (us / them).
- Each control is an optimistic mutation (`useSetMatchStat` upsert; MOTM/score → an event update); a failure
  rolls back and shows an inline note. Per-row saving state; no double-write on a fast double-tap.
- Managers/admin only (the RLS refuses others; the route is manager-guarded).
- Four states: loading the squad+stats, empty ("Pick a squad first" when none selected), error, populated.

**Out**
- Non-squad players (collect only for the selected 20). Live scoreboard sharing (later). Any stat beyond X4.

## Acceptance criteria
- [x] **AC1** — The screen lists the selected matchday squad with per-player goal/assist/yellow steppers, a red toggle and minutes.
- [x] **AC2** — Each change writes optimistically to `match_stats` and survives a reload; a rejected write rolls back with a note.
- [x] **AC3** — MOTM sets `events.motm_user_id`; the score sets `score_us`/`score_them`.
- [x] **AC4** — Editing an old match updates the same rows (idempotent), not duplicates.
- [x] **AC5** — A player/non-manager cannot reach it and, via the API, cannot write (RLS).
- [x] **AC6** — Four states handled; no matchday squad → a clear "pick a squad first" empty pointing to Selection.

## Implementation notes
- `src/features/stats/` — the collection screen; `useMatchStats(eventId)` (read) + `useSetMatchStat` (upsert,
  optimistic per D48) in `src/api/match-stats.ts`. Reuse the squad read (`useEventSquad`) and member names.
- Steppers clamp at 0 (yellows at 2); minutes 0–200. Score/MOTM reuse the event update hook.

## Data and API surface
Upsert `match_stats`; update `events` (motm/score). Reads `event_squad` + `match_stats` + member names.
