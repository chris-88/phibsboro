# S18.5 — Last sign-in on the admin user manager

| | |
|---|---|
| **Epic** | 18 — Manager conveniences (post-v1.3.0) |

| **Size** | S |

## Goal
An admin can see when each person last signed in, from the Users screen (Chris, 2026-09-16) — a quick
way to spot who has actually opened the app.

## Context
`auth.users.last_sign_in_at` is off-limits to clients, so an admin-only security-definer RPC returns
it per user, role-gated in the body (an admin gets every row, anyone else none — the stats-RPC shape).
The Users read already composes profiles/team_members/teams; this adds a fourth read and joins by id.

## Scope
**In**
- `admin_last_sign_in()` → `(user_id, last_sign_in_at)`, admin-only, from `auth.users`.
- `useAllUsers` joins it; `AdminUser.lastSignInAt`.
- Each user card shows "Last seen {date}" (Dublin, `formatEventTime`) or "Never signed in".

**Out**
- Sign-in history / counts. Sorting or filtering by last seen. Any non-admin surface.

## Acceptance criteria
- [x] **AC1** — Each user shows their last sign-in, or "Never signed in".
- [x] **AC2** — The value comes from an admin-only RPC; a non-admin gets no rows, anon no execute.

## Implementation

- `AdminUsersScreen` — the "Last seen" line.
- `tests/rls/rpc-admin-users.test.ts` — admin rows / non-admin none / anon no-execute.
