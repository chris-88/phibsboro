# S18.6 — Last active (interaction), not just last login

| | |
|---|---|
| **Epic** | 18 — Manager conveniences (post-v1.3.0) |
| **Status** | Done |
| **Depends on** | S18.5 (last sign-in) |
| **Size** | S |
| **Risk** | low — one throttled single-row update |

## Goal
`last_sign_in_at` (S18.5) only marks the login moment; someone can be using the app for hours after.
The Users screen should show **last interaction**, cheaply (Chris, 2026-09-16 — "without it being too
heavy").

## Context
`profiles.last_seen_at`, bumped by a security-definer `touch_last_seen()` (so a user stamps only
their own row, with no broad profiles self-update policy). The client **throttles** it to at most once
every 5 minutes via `localStorage`, firing on mount, on each navigation, and on tab-refocus — one
cheap update, not a write per action. The screen shows the **later of** `last_seen_at` and the login
time as "Last active".

## Scope
**In**
- `profiles.last_seen_at` + `touch_last_seen()` (own row only).
- `useLastSeen(active, pathname)` in the root layout: throttled touch for a signed-in user.
- The Users card shows "Last active {later of interaction / login}" or "Never signed in".

**Out**
- A precise activity log or session count. Per-action writes (deliberately throttled). Showing it to
  anyone but an admin.

## Acceptance criteria
- [x] **AC1** — Continuing to use the app updates "Last active", not only logging in.
- [x] **AC2** — At most one write every ~5 minutes per active device (throttled), best-effort.
- [x] **AC3** — A user stamps only their own row; anon holds no execute.
- [x] **AC4** — "Last active" is the later of interaction and login; "Never signed in" when neither exists.

## Implementation
- `supabase/migrations/20260916220000_last_seen.sql` — the column + `touch_last_seen()`.
- `src/features/auth/use-last-seen.ts` — the throttled heartbeat (unit-tested); mounted in `RootLayout`.
- `admin-users` read gains `last_seen_at`; `AdminUsersScreen` shows the later of the two.
- `tests/rls/profiles.test.ts` — own-row stamp + anon no-execute.

## Definition of done
- [x] ACs met; throttled + best-effort; `typecheck`/`lint`/tests/build green. Touch verified live (rolled back).
