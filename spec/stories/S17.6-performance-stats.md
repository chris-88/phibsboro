## Goal
The Stats tab can show match performance: per-player appearances, goals, assists, cards, minutes and MOTM
count — the player their own, a manager the squad leaderboard.

## Context
[X6/X8](../00-decisions-v1.3.0.md). Aggregates `match_stats` + `events.motm_user_id`. See the
`performance_stats` RPC in [data-model-v1.3.0.md](../data-model-v1.3.0.md).

## Scope
**In**
- `performance_stats(p_team_id)` — role-aware, aggregating the team's matches.
- A `usePerformanceStats(teamId)` hook + a Performance view: a manager sees the squad leaderboard (sortable —
  top scorer, assists, etc.); a player sees their own totals. Appearances, goals, assists, yellows, reds,
  minutes, MOTM.
- Four states, incl. "no matches with stats yet".

**Out**
- The Stats tab shell (S17.7). Attendance (S17.5). Collection (S17.4).

## Acceptance criteria
- [ ] **AC1** — A manager gets the squad's aggregated performance; a player gets only their own line.
- [ ] **AC2** — Totals match a known `match_stats` fixture (goals/assists/cards/minutes/MOTM/appearances).
- [ ] **AC3** — A non-member/anon gets nothing.
- [ ] **AC4** — Four states, including the empty "no match stats yet".

## Definition of done
- [ ] ACs met; four states; new RLS rows pass on the next on-demand run; `typecheck`/`lint` clean, tests pass.
