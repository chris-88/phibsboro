## Goal
The top-right ⋮ menu becomes the user's profile picture, which opens a profile screen showing their
essentials and the actions the menu used to hold.

## Context
[W9](../00-decisions-v1.2.0.md). The header avatar shows on every `nav` route and links to `/profile`. The
profile carries **essentials only** — stats/attendance are the future Stats tab (W8), not here.

## Scope
**In**
- A `/profile` route (guard `authed`, chrome `nav`), reached by the header avatar.
- The header renders `<Avatar>` (self) as a link to `/profile` in place of `AppShellMenu`.
- Profile content: large avatar with an edit/upload + remove control (S16.2); name; phone; the user's teams
  with their role each; and the moved actions — **Send feedback** (opens `FeedbackSheet`), **Add to home
  screen** (the install sheet, when applicable), **Sign out**.
- Four states for the memberships read (loading/empty/error/populated); "You're on no teams yet." empty.

**Out**
- Any stats/attendance (Stats tab, later). Editing name/phone (admin-controlled). Viewing others' profiles.

## Acceptance criteria
- [ ] **AC1** — The header shows the signed-in user's avatar (photo or initials) on nav routes; tapping it opens `/profile`.
- [ ] **AC2** — `/profile` shows the avatar (with upload/remove), name, phone, and each team + role.
- [ ] **AC3** — Send feedback, Add to home screen (when relevant) and Sign out all work from the profile — nothing the ⋮ menu did is lost.
- [ ] **AC4** — The ⋮ overflow menu no longer renders anywhere.
- [ ] **AC5** — Four states handled; a signed-in user with no team sees the empty line, not a broken screen.
- [ ] **AC6** — Uploading/removing a photo updates the header avatar and the profile avatar without a reload.

## Implementation notes
- `src/features/profile/routes/ProfileScreen.tsx`; a `ProfileButton` (header) using `<Avatar>` from S16.2.
- Reuse the current-user read (name, phone, memberships, avatar_path) — no new membership query if
  `useCurrentUser` already carries them. Reuse `useSignOut`, `FeedbackSheet`, the install sheet hook.
- Delete `AppShellMenu` (and its test) once the header points at `ProfileButton`.

## Data and API surface
Reads the current user (S2.9) + `avatar_path`. Writes via S16.2. No new table.

## UI states
| Screen | Loading | Empty | Error | Populated |
|---|---|---|---|---|
| `/profile` | skeleton | "You're on no teams yet." (teams block) | inline retry (teams) | avatar, name, phone, teams, actions |

## Test plan
- **Unit** — the header shows the avatar and links to `/profile`; the profile renders essentials + actions;
  sign out / feedback / install fire; the ⋮ menu is gone.
- **Manual** — set a photo, see it in the header; sign out from the profile.

- [ ] ACs met; four states handled; `typecheck`/`lint` clean, tests pass.
