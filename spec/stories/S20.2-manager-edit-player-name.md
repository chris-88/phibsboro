## The report
#7 "Managers should be able to correct player names so they are correct for the team sheet"

## Goal
A wrong name (typo at sign-up) can be fixed so the team sheet, roster and shares read right.

## Context
The app stores one `profiles.name` per person, read by the team sheet, roster and every share. There's no
client write path to another person's profile today (profiles is own-row + RPC). So this needs a
security-definer RPC.

## Proposed shape (Z1, confirm)
- `set_member_name(user_id, name)` — security definer; callable by an **admin, or a manager of a team the
  person is on** (mirrors the on-behalf write, S18.1); validates 1–80 chars; audited.
- UI: an inline edit / small dialog on the member list (Squad → Members, and Admin → Users).

## Acceptance criteria
- [ ] **AC1** — A manager fixes a name for a player on their team; it updates everywhere the name is read.
- [ ] **AC2** — RLS/RPC refuses a non-manager / a player not on a team they manage.
- [ ] **AC3** — Validated (1–80 chars, trimmed); the write is audited.

## Open question (Z1)
- Admin-only, or managers for their own team too? (Proposed: managers for their team + admins.)
