## Goal
The database lets an admin assign any user to any team with any role, in one call, so an admin can repair
membership state directly. Nothing user-facing yet.

## Context
[W6](../00-decisions-v1.2.0.md). `team_members` is RPC-only — the single policy is SELECT; there is no client
write path (joins go through `join_team_by_token`/`_by_event`). Role changes (`set_member_role`) and removal
(`remove_member`) already exist and admit an admin; the missing piece is a direct **assign**.

## Scope
**In**
- `admin_set_membership(p_team_id uuid, p_user_id uuid, p_role public.member_role)` — `SECURITY DEFINER`,
  `set search_path = ''`, `is_admin()` guard (else `not_authorised`), upsert on the `(team_id, user_id)` PK
  setting the **exact** role (an admin may downgrade, unlike the join-link upgrade-only merge, D26).
- `revoke execute from public, anon; grant execute to authenticated`.
- Reaches inactive teams (a repair tool).
- RLS suite rows (S1.4 grows): an admin assigns a brand-new membership and re-assigns to change the role
  (up and down); a non-admin and anon are refused; the row lands with the exact role.

**Out**
- The screen (S14.2). Role-change and removal (reuse `set_member_role`, `remove_member`). Account
  creation/deletion (out of scope, W6).

## Acceptance criteria
- [ ] **AC1** — An admin calling `admin_set_membership` for a user with no row on the team creates it with the
  given role.
- [ ] **AC2** — Calling it again with a different role sets that exact role (manager→player as well as
  player→manager).
- [ ] **AC3** — A non-admin (manager or player) is refused `not_authorised`; anon has no execute.
- [ ] **AC4** — Works for an inactive team.
- [ ] **AC5** — `team_members` gains no direct client INSERT/UPDATE policy (the RPC stays the only write path).

## Implementation notes
- Mirror the S1.3 RPC shape (the join RPCs). `on conflict on constraint team_members_pkey do update set role =
  excluded.role`.
- Add the RPC in a new migration; regenerate `database.types.ts` (it appears under `Functions`).

## Data and API surface
New RPC `admin_set_membership`. No table/policy change. A `useAdminSetMembership` mutation lands in S14.2.

## UI states
Not a UI story.

- **Unit / E2E / Manual** — none.
